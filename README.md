# My Portfolio

## About
A clean, responsive, and interactive personal portfolio website designed for the Builders Day challenge. It features a "Dark Developer/Terminal" aesthetic with a Bento box layout for skills and standard grid for projects.

## Technologies
- HTML
- CSS (Custom Keyframe Animations & Transitions)
- Tailwind CSS (Bonus Challenge - used for Layout, Typography, Colors, Spacing, and Responsive Design)
